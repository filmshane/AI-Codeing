4. WEBSITE VISITOR PATH (THE REAL PRODUCT)
================================================================

Browser
  -> firstpropertyinvestment.us
  -> index.html loads:
       <elevenlabs-convai agent-id="agent_6201m06jgd6tf7arch24867h9a44">
       plus the ElevenLabs widget script from unpkg

Widget (top-right, voice + typed text)
  -> ElevenLabs ConvAI session

Inside that session, ElevenLabs does:

  1. Hear the visitor
       ASR: scribe_realtime  quality=high

  2. Decide when they finished talking
       ConvAI VAD / turn-taking

  3. Think
       llm = custom-llm
       It does NOT use ElevenLabs' Gemini for Morgan.
       It POSTs OpenAI-style chat completions to THIS server:

         https://firstpropertyinvestment.us/api/reception/v1
           /chat/completions

       model_id: grok-4.20-reasoning
       Authorization: Bearer <MORGAN_LLM_BEARER>
         (a gate token we issued; not the Grok OAuth JWT)

  4. Speak
       TTS model: eleven_v3_conversational
       voice_id:  XrExE9yKIg1WjnnlVkGX  (Matilda)
       expressive_mode: true
       enable_phoneme_tags: true

  5. If she has name + phone + AI-call consent
       POST take_lead webhook to THIS server
         https://firstpropertyinvestment.us/api/reception/tools/take_lead
         header X-Morgan-Tool-Secret

5. WHAT THIS SERVER DOES WHEN ELEVENLABS CALLS IT
================================================================

nginx  /etc/nginx/sites-available/firstpropertyinvestment.us
  /api/reception/  ->  127.0.0.1:8793/api/

Local app
  /opt/voice-receptionist
  systemd: voice-receptionist.service
  listen:  127.0.0.1:8793   (not public except through nginx)

Grok bridge  POST /api/v1/chat/completions
  1. Reject unless Authorization matches MORGAN_LLM_BEARER
  2. Force model grok-4.20-reasoning
  3. Forward to hermes-proxy-xai at 127.0.0.1:8645/v1/chat/completions
  4. That proxy attaches Shane's Hermes xAI / SuperGrok OAuth
     (same login Hermes uses). The rotating JWT never sits in
     ElevenLabs.

Lead webhook  POST /api/tools/take_lead
  1. Reject unless X-Morgan-Tool-Secret matches
  2. Write /opt/voice-receptionist/data/reception.db
  3. POST the lead to /send.php as source=website_morgan
     (email + leads-inbox jsonl)

So: ears and mouth = ElevenLabs. Brain and CRM write = this host.
